# Olist Brazil Ecommerce Data Analytics Engineering Project

The end goal of this project is to provide meaningful insights on the
Olist Ecommerce dataset. The dataset has information of over 100k
orders from 2016 to 2018 made at multiple marketplaces in Brazil.
Data includes order status, price, payment, among others.

This project aims to go through the following phases:
- Establish connection to Snowflake
- Download the public dataset from Kaggle
- Ingest the data in Snowflake
- Create dbt layers - staging, intemediate, mart
- Use the mart layer as a source for a BI dashboard

Tech stack:
- dbt
- SQL
- Python
- Snowflake
- Tableau / Power BI
- Git
